# bank-loan-analytics
The Bank Loan Analytics Dashboard is an end-to-end data analytics project developed using SQL and Power BI to analyze. The main objective of this project is to help financial institutions monitor loan performance, track borrower behavior, and identify potential lending risks through interactive dashboards and KPI analysis.

# 🚀 Project Overview

This project focuses on analyzing bank loan data to generate business insights and interactive dashboards.

The dashboard helps track:

- Total Loan Applications
- Funded Amount
- Amount Received
- Interest Rate
- Debt-to-Income Ratio (DTI)
- Good Loan vs Bad Loan Analysis
- Loan Status Performance
- Monthly Trends
- State-wise Loan Distribution
- Employee Length Analysis
- Home Ownership Analysis
- Purpose-based Loan Analysis

# 🧠 Key Insights

- Most loans were categorized as Good Loans.
- Fully Paid loans contributed the highest repayments.
- 36-month loans had more applications than 60-month loans.
- Mortgage customers received the highest funded amounts.
- Debt Consolidation was the most common loan purpose.
